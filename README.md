# 雨夜心事 · 倾诉网站

一个给"刚经历离别"的你，用来安放心情的网站。背景是忧郁的雨夜，缓缓落下的雨丝，配上合成器自动演奏的伤感钢琴旋律。

## 文件结构

```
website/
├── index.html    # 主页面
├── style.css     # 忧郁深蓝风格样式
├── script.js     # 雨滴/粒子背景 + 钢琴旋律合成
└── README.md     # 说明文档
```

## 如何使用

### 方式一：本地直接打开
直接用浏览器打开 `index.html` 即可，无需服务器。

### 方式二：本地服务器启动
```bash
python3 -m http.server 8080
```
浏览器访问 `http://localhost:8080`

### 方式三：部署到 GitHub Pages / 任意网站空间
把三个文件上传开启即可获得公开网址。

## 站点特点

- 🌧️ 自动落下的**雨丝动画**，配合深蓝忧郁的暗色氛围
- ✨ 缓慢漂浮的尘埃粒子，营造凄清的夜
- 🎹 右下角音乐按钮 — 点击后用 **Web Audio 现场合成**一段 A小调伤感钢琴曲（无需音频文件，100%可靠）
- ⌨️ 打字机效果，诉说不出口的话
- 📝 "给未来的信"记事本 — 写下心情，自动保存在本地，下次打开还在
- 📱 完全响应式

## 站长权限

你是网站站长和倾诉者，拥有完全控制权：
- 修改 `index.html` 里标题、诗句、那张"没说出口的话"
- 修改 `script.js` 里的 `lines`（打字内容）和 `melody`/`chords`（钢琴旋律，可改音高定制曲调）
- 修改 `style.css` 调整配色与氛围

### 想换成其它伤感 BGM？
如果不想用合成旋律，可以在 `index.html` 的 body 里加一个 `<audio>` 标签，把 `script.js` 里音乐部分替换成播放那个音频即可（告诉我，我帮你改）。
